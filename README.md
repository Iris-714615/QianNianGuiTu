# 千年归途 · 完整两幕 v1

2026-10-31 整合版。博物馆搜证与潜行 → 北京古董商暂存间 → 拼合残图 → 信封 / CG → 旅程结尾。

## 试玩

- 同级目录的 `千年归途-完整游戏-离线试玩.html` 内置代码、图像、音乐和配音，可交给队友在桌面浏览器打开。正式 CG 不包含在内。
- 也可以启动源码：Node.js 20.19+ 或 22.12+，运行 `npm ci`、`npm run dev`。开发栈沿用 React 19 / Vite 6；博物馆原 Canvas 逻辑作为可卸载场景接入。
- `npm run build` 生成 `dist/client` 静态站点；`npm run preview` 预览构建；`npm run offline` 重新生成同级离线 HTML。
- 主目标为桌面横屏 16:9，已检查 1280×800 与 960×540 视口。竖屏和手机真机不是本版验收范围。

## 操作与规则

WASD / 方向键移动，E 调查，J 证据册，Esc 暂停。可点击地面行走、点击物件自动走近，第二幕有“指引”按钮。抽屉和选择题支持键盘。

完整度共 3 格。答错、被保安发现、碰危险木板会留下伤痕。1 格时移速为 85%；0 格时暂时力竭，选择安全恢复后回到 3 格，已找到的证据与残图保留。**所有状态四肢完整，没有断肢或身体拆散。** 通关第一幕、正确拼合第二幕时恢复完整度。

右上方有统一声音、音量、试听、操作说明和保存回首页。声音在用户点击后启用。存档保存在当前浏览器的 localStorage；不同网址、浏览器或文件环境的存档不共享。若浏览器不允许保存，仍可完成当次游戏。

## 本版整合

- 单一首页、统一角色、证据传递、完整度、声音、暂停、存档和终章。
- 第一幕真实传递编号 33-670、1933 年购入、1933-07-10 通信、北京和 Otto Burchard。第二幕不再使用演示编号 047。
- 金色狮子是苏醒后的化身；图录保留文物原貌，避免“抬爪石狮”的辨认线索失效。
- 主角四向行走、四向调查、伤痕状态、疲惫、发现反应和修复光效；保安补齐四向行走，不再以正面代替背面。
- 第一幕六类家具按房间正面透视适配；角色调查时朝向物件。第二幕沿用原房间与一体式九格木柜，不改变柜体美术坐标。
- CG 可通过配置或本机文件载入，失败有重试、重新选择及进入结尾入口。

## CG 接入

将正式影片放入 `public/media/ending.mp4`，修改 `public/game.config.json`：

```json
{"videoUrl":"media/ending.mp4","nextStageUrl":"","videoTitle":"来时的路"}
```

重新构建后，静态站点会在打开信封时播放。建议 MP4 / H.264 + AAC / 16:9，播放器采用 contain，不拉伸影片。可播放、暂停、跳过；正常播放结束自动进入终章。

单文件 HTML 默认不嵌入正式 CG。打开信封时可以用文件选择器载入本机影片；这个文件引用仅在当前会话有效。若把配置指向相对 MP4，请把影片与 HTML 按相同相对目录一起交付。如需将大型影片也内嵌，应另行评估体积。

## 检查结果与限制

23 项玩法 / 音频 / 整合单元检查、4 项静态构建检查通过。两次真实操作走通两幕，其中熟悉答案后的无误路线实测 **170.27 秒**（不含 CG，不代表新玩家首次游玩时长）。验证了两幕力竭恢复、证据保留、存档续玩、正确抽屉、错误拼合、缺 CG 继续、实际测试 MP4 播放与播放结束转场。

最终单文件在本地 HTTP 服务中检查。浏览器工具的安全策略不允许直接导航 `file://`，因此未把“双击文件环境已实测”列为通过；该文件的运行资源已内嵌，后续请在目标电脑直接打开做最后一次交付检查。正式 CG 仍待团队提供；未部署公网、未做手机真机测试。
