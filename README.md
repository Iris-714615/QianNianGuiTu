# 千年归途 · 暂存之物

本仓库为 H5 游戏第二场景完整工程。

公开试玩入口（首次 Pages 发布完成后生效）：https://iris-714615.github.io/QianNianGuiTu/

包含场景内九格旧木柜、三片记忆探索、自动对白、24 段本地合成配音、拼图和信封过场。第一场景与正式影片由团队继续整合。


可编辑、可热更新的 H5 叙事探索游戏。React + DOM 图片角色/背景 + Canvas 特效，Vite 开发服务。简化、清楚的低多边形 2.5D 俯视美术。

## 本地开发与热更新

安装 Node.js 22，然后在工程文件夹运行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

打开 http://127.0.0.1:4173/ 。修改 `src/App.jsx`、`src/story.js`、`src/styles.css` 后，开发页面会热更新。最终发布用 `npm run build`，文件生成在 `dist/client`。

## 本关内容

开场承接博物馆关卡：石狮已经确认自己的编号，却仍未找回故土。

1. 旧铜像：“好久不见。你怎么，又回到这里来了？”
2. 调查上方打包台，拾取未烧尽的第一片残图。
3. 调查左下盖布木箱，掀开旧布，轻轻抽出第二片；读到“乙柜 · 下层 · 火印朝内”。
4. 走到右墙边的旧木柜，在房间内直接点击乙柜下层的把手拉开抽屉，再点击纸片取走。错误抽屉内部为空，再点可推回。窄屏查看时会推进房间镜头，可点击“退出查看”退回。
5. 回到旧铜像身边交互，点击两片图交换位置，让河流和红线接上。
6. 拼合后得知上一站“海隅货栈”；铜像将图收进信封。
7. 点击“打开信封 · 继续归途”，播放正式影片或内置回忆预演。

第一关“辨认身形找编号 → 按编号查购买记录 → 躲避保安取得档案”由另一场景负责，本工程没有冒充已实现该关。两关衔接方法见 `HANDOFF.md`。

## 操作

WASD / 方向键移动；E 互动；Shift 慢行；J 记忆手札；Esc 返回/暂停。点击地面或物件也能自动绕开箱子前往。H5 触屏可直接点地面与物件。

右侧散落木板会触发旧伤、短暂跛行并留下石屑。站在原地不会重复计伤，可以绕开。

## 声音

点“开启声音”或开始旅程后，由用户手势启动真实的 `public/assets/ambient.wav`。48 秒原创五声音阶氛围音乐循环，另有脚步、拾取、拼合与磕碰效果。提供音量滑杆和“播放试听音”。按钮依据播放成功结果更新，失败不会谎报已开启。

## 视频接入

把 MP4（推荐 H.264 + AAC）放到 `public/media/next-chapter.mp4`，将 `public/game.config.json` 改为：

```json
{"videoUrl":"media/next-chapter.mp4","nextStageUrl":"","videoTitle":"来时的路"}
```

也可以在信封界面选择本地影片，用于现场演示。浏览器选择后生成临时地址，不上传。没有影片时播放内置静帧镜头预演；这是预演，不是真实视频成片。开始影片时自动停掉游戏背景音乐，影片有播放控制和失败回退。

## GitHub Pages

工程已含 `.github/workflows/pages.yml`。将工程推送到你自己的仓库，主分支为 main，然后在仓库 Settings → Pages 中把 Source 设为 GitHub Actions。后续推送 main 将构建并部署；成功地址会显示在 Actions 的 github-pages 部署中。相对资源路径适配 `/仓库名/` 子目录。

本仓库通过 GitHub Actions 构建并部署 GitHub Pages；首次需要在 Settings → Pages 将 Source 设置为 GitHub Actions。后续推送 main 自动更新。

## 美术与实现范围

- `public/assets/lion.png`：按所提供真实文物的端坐、抬爪姿态改编的低多边形角色。
- `room-integrated.png`：当前实际使用的 2.5D 房间，含右墙九格木柜、冷色窗光、铜像与文物。`room.png` 为原版房间，不要误用它覆盖最终背景。
- `record.png`：明显的档案/线索物件。
- `map.png`：可分片拼合的来路地图。
- `*-legacy.png`：上版备用背景、角色，资源失败时回退。
- `ambient.wav`：本地原创音乐。

角色采用独立透明精灵位移与轻微重心动画，尚未制作完整四向逐帧动作。人物、地点、路线图和装运信息为艺术化虚构。

## 最新交互调整

现在走近旧铜像会自动交谈，气泡显示在场景内并自动播放合成配音，玩家可边走边听。走近物件也会自动出现旁边的小提示卡。普通拾取改为现场气泡、新线索提示及目标变化，不再打开中央遮罩。

地图仍需返回铜像处，通过近旁的“拼合残图”动作主动开始。空格可推进正在显示的对话，E 用于物件动作。进度会临时保存在当前浏览器标签中，开发刷新尽量保留探索进度；“重新开始”可清空本次试玩。

配音资源为 `voice-01.wav` 至 `voice-24.wav`。文案在 `src/voice-script.json`，时长与对应文件在 `src/voice-manifest.json`。本地音频随工程提供，无需在线语音服务。

详细对标与实际流程见 `交互对标与流程.md`。
