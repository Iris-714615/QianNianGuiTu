受伤移动态叠加裂纹；静止时使用对应方向的伤痕图。0 格疲惫仍保留四肢。恢复使用状态切换和暖光圈，不使用身体部件拼装。发现残图有短暂反应；无障碍“减少动态效果”会关闭额外动画。

## 房间适配

第一幕的 facing-wide / cover / desk / files / plinth / board 为正面俯视素材：正面边缘平行房间横轴、深度向画面上方，取代不匹配的斜向等角素材。透明底、等比缩放，脚点 / 家具底部对齐地面。档案柜限高避免被画面上缘截断。

第二幕保留房间烘焙柜体的方向；主角行动与调查姿态按房间的屏幕横纵轴映射。

## 生成记录

使用内置 imagegen，未调用额外 CLI 图像 API。生成后通过技术切帧、统一尺寸和资源接线处理，不把整张参考海报贴进场景。源图在 art-source；可运行图在 public/assets。

最终提示约束：以用户金狮图为身份参考；固定俯视 2.5D 相机；四方向、同一脚底基线、透明底；轻重伤只增加伤痕与疲惫，四肢永远完整。保安沿用 A06 制服，在南东 北西各补 4 帧行走，北向只露背面。家具沿用 A10—A14 木材、玻璃、铜件，改为正面水平轴及上方纵深，不允许整件斜转、裁断或额外背景。

图像工具预览有时显示透明像素里的底色；实际 PNG 有 alpha，游戏中透明显示。权利来源延续用户提供材料；正式对外发行前需由项目方确认原始素材与品牌授权。本次没有联网发布。
